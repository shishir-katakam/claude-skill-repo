# Research Paper Publisher Pro

This skill supports end-to-end paper generation and submission readiness.

## Usage
1. Configure `config/settings.yaml`.
2. Track context in `context_manager/session_state.json`.
3. Run research + cross verification before drafting.
4. Generate references and format for target publisher.
5. Export and run submission checklist.
