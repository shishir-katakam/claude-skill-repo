# Research Paper Skill

Use this skill when the user wants to ideate, research, write, verify, and format an academic paper.

## Workflow
1. Capture user profile and constraints in `context_manager/context_reminder.md`.
2. Run search + screening in `literature_review/` before writing claims.
3. Cross-check every technical claim using `cross_checker/verification_checklist.md`.
4. Draft sections with `paper_writer/section_templates.md`.
5. Build citations with `references/citation_styles.md` and scripts in `references/`.
6. Apply QA in `quality_assurance/review_checklist.md`.
7. Choose venue format from `formatting/` templates.
8. Preview using `viewer/paper_preview.html`.

## Rules
- Never invent citations.
- Every non-trivial claim must map to a source.
- Keep novelty realistic for B.Tech level while academically rigorous.
- Explicitly mark assumptions, limitations, and future work.
