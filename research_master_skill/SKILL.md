# Research Master Skill

Use this skill for long-running research projects where continuity and verification are essential.

## Components
- `memory/`: persistent state and context retrieval.
- `tools/`: web search, cross-checking, citation generation.
- `computation/`: data analysis and performance-critical templates.
- `viewer/`: lightweight progress dashboard.
