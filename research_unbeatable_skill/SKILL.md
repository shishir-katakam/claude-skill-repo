# Research Unbeatable Skill

Use this skill when a user wants one complete system for producing high-quality research papers from idea to submission.

## Quick Routing
- For topic selection and planning: read `workflows/topic_selector.md` + `workflows/quick_start.md`.
- For continuity across long sessions: use `memory/context_manager.py` and `memory/project_state.json`.
- For literature discovery and source quality: use `research/web_search_agent.py` + `research/source_validator.py`.
- For claim reliability: run `verification/fact_checker.py` and update `verification/cross_ref_matrix.md`.
- For writing: use templates in `writing/`.
- For final compliance: run `quality/` checks and `export/submission_checklist.md`.

## Hard Rules
1. Never fabricate references, DOIs, data, or experimental outcomes.
2. Every technical claim must map to evidence in `verification/verification_log.md`.
3. Keep scope realistic for an undergraduate timeline unless the user explicitly expands scope.
4. Always include limitations and reproducibility notes.

## Standard Workflow
1. Initialize project context.
2. Select topic and hypotheses.
3. Collect and score literature.
4. Design methodology and experiments.
5. Draft sections.
6. Verify claims and references.
7. Run QA + style checks.
8. Format for target venue.
9. Preview and export.
